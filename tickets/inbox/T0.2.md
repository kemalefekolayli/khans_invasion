# TICKET: T0.2 — Build Autoplay Test Harness (SimulationController)

## Context
No automated testing exists. We need a headless harness that auto-advances turns and exercises systems. This is the foundation for all future "Done When" verification — every later ticket's test conditions depend on this harness existing.

## Must Have
- [ ] A `SimulationController` MonoBehaviour (in a dedicated test scene or boot flag) that:
  - Auto-calls `TurnManager.Instance.EndPlayerTurn()` each frame/tick
  - Runs in two modes: **AI-only** (no player input) and **scripted-player** (drives player armies/generals via public APIs)
- [ ] A 10-turn smoke test that asserts: no null refs, no negative gold/pop, no stuck states, no exceptions
- [ ] A pass/fail report written to a log file (e.g., `simulation_report.txt` in project root or `Logs/`)

## Nice to Have
- [ ] Configurable turn count (serialized field)
- [ ] Per-turn snapshot logging (gold, pop, army counts per nation)

## Done When
- [ ] Harness runs 10 turns in AI-only mode without errors
- [ ] Report file generated showing PASS
- [ ] Code compiles cleanly (no syntax errors, all referenced types exist)

## Manual Check
NO — the agent can verify by running the harness and checking the report file

## Files Touched
- `Assets/code/Testing/SimulationController.cs` (new)
- Possibly a new test scene or a boot flag in an existing scene

## Branch
`feature/t0.2-autoplay-harness`

## Notes for the Agent
- The game uses `TurnManager.Instance.EndPlayerTurn()` to advance turns. The AI turns are processed automatically via `OnAITurnsStart`.
- `ArmyManager.Instance.GetAllArmies()`, `PlayerNation.Instance`, and `NationLoader` are the key APIs.
- The harness should be a MonoBehaviour you can add to a scene. If creating a new scene is complex, add a `[RuntimeInitializeOnLoadMethod]` or a boot flag so it can run from the existing scene.
- Keep it simple — this is a smoke test, not a full test framework. Unity Test Framework (EditMode/PlayMode) is optional; a plain MonoBehaviour that logs results is acceptable for now.
- Do NOT modify game systems to make the harness work. If the harness reveals bugs, note them in the result — do not fix them here (that's what the other tickets are for).
