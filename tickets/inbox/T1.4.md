# TICKET: T1.4 — Quest Expansion (New Quest Types + New Quests + Threshold Checks)

## Context
Currently the quest system only supports counter-style quests (`IncrementProgress`) driven by 5 events, and there are only 5 wired quests. User wants: economy quests, military quests, population quests, and deeper tiers of existing ones, arranged as an unlock tree.

Note: Some new quests are VALUE-based ("reach X gold", "reach X population"), which the current `IncrementProgress` model cannot express. The manager needs a threshold-check path in addition to increments.

## Must Have
- [ ] Add new `QuestType` values in `QuestEnums.cs`:
  - Economy: `AccumulateGold` (reach X gold), `ReachIncome` (reach X per-turn income)
  - Population: `ReachTotalPopulation` (sum of owned provinces' current pop)
  - Military: `RecruitTroops` (total recruited troop count), `ReachArmySize` (sum of player army sizes)
- [ ] `QuestManager` gains a threshold/check path: e.g. `CheckValueQuests()` that for each quest reads the appropriate current value (gold, income, total pop, army size) from `PlayerNation`/`ArmyManager` and marks complete when `value >= targetCount`. Call it from relevant events: `OnPlayerStatsChanged`, `OnPopulationGrowth`, `OnArmySpawned`, `OnTurnEnded` (whichever apply). Guard against repeated firing (already-completed quests are skipped in the existing loop).
- [ ] Add ~8–10 new `QuestData` assets under `Assets/Quests/` (e.g. `Quest_7.asset` … `Quest_16.asset`) covering: deeper raid (10), deeper build (15), deeper conquer (10), deeper defeat (10), economy (accumulate 300 gold, reach 50 income), population (reach 800 total pop), military (recruit 100 troops, army size 150), plus sensible rewards (mix of Gold, PopulationCapacity, TradeIncome, NewGeneral). Set `prerequisiteQuestId` so the whole set forms an unlock TREE (some quests share a parent, some have multiple children), not a single line.
- [ ] Wire all new quest assets into `GameScene.unity` `QuestManager.allQuests`.

## Done When
- [ ] New quests appear in the quest panel with correct titles/descriptions/rewards
- [ ] Value-based quests (gold, population, income, army size) complete when the player reaches the threshold
- [ ] Counter quests (deeper raid/build/conquer/defeat) progress via existing events
- [ ] Quest tree unlocks correctly (each new quest's prerequisite gates it)
