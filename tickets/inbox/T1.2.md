# TICKET: T1.2 — Province Info UI Live Refresh + Game Font Replacement

## Context
Two user-reported polish issues:
1. **Province UI not refreshing live.** `ProvinceInfoDisplay` (the world-space panel in `ProvinceCanvas.prefab`) only re-reads `ProvinceModel` on `GameEvents.OnProvinceEnter`. When the player builds a building or recruits troops while standing in a province, the model is mutated in place but the panel keeps stale numbers until the player leaves and re-enters. The model data is always correct — the UI just doesn't listen to the relevant events.
2. **Font is ugly.** The active runtime font comes from `GameFontManager.resourcesFontPath`. The StartScene auto-created instance uses the script default `Fonts/KiwiSoda`, while the serialized GameScene manager uses `Fonts/VCR_OSD_MONO_1.001` — so which font wins depends on scene flow (inconsistent). Province/city name labels fall back to `TMP_Settings.defaultFontAsset` (LiberationSans SDF). User wants a single stylish font.

## Must Have
- [ ] `ProvinceInfoDisplay` subscribes to `GameEvents.OnBuildingConstructed`, `OnPopulationGrowth`, and `OnPlayerStatsChanged` (in `OnEnable`/`OnDisable`) and calls `UpdateDisplay()` when the event's province is the currently displayed province (or, for stateless `OnPlayerStatsChanged`, when a province is currently shown)
- [ ] Add new font `Assets/Resources/Fonts/MedievalSharp.ttf` (Google Fonts, OFL) with its `.meta`
- [ ] `GameFontManager` script default `resourcesFontPath` -> `Fonts/MedievalSharp`
- [ ] Serialized GameScene `GameFontManager` `resourcesFontPath` -> `Fonts/MedievalSharp`
- [ ] `CityNameFont` fallback uses the runtime/active font instead of `TMP_Settings.defaultFontAsset` so province name labels use the same font

## Done When
- [ ] `ProvinceInfoDisplay` refreshes population/income/trade immediately after a building is constructed and after recruiting troops, without leaving the province
- [ ] All TMP text uses MedievalSharp consistently (city names included)
- [ ] Code compiles cleanly in the Unity editor

## Manual Check
YES — in-game: stand in a province, build a building (pop/income updates instantly), recruit troops (pop updates instantly); verify the new font everywhere including province name labels.
