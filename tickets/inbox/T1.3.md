# TICKET: T1.3 — Quest System Core Fixes (Firing Logic + Unlock Semantics + Rewards)

## Context
Quest system audit found multiple broken/incorrect behaviors in `QuestManager.cs` and related files:
1. `GameEvents.NationDestroyed` is NEVER invoked anywhere → "Destroy a nation" quest impossible.
2. `OnArmyDefeated` counts the player's OWN lost armies (no ownership filter) → "Defeat 3 armies" progresses when the player loses.
3. Quest asset data bugs: Quest_1 `targetCount=1` but title says "Raid 3 Provinces"; Quest_6 reward description says gold but type is MoveCapitalAbility.
4. Quest_6 asset is orphaned — not wired into `GameScene.unity` `QuestManager.allQuests`.
5. `NewGeneral` reward is broken in scene config: `generalSpawnPoint` is null and `generalPrefab` points to HorsePrefab; also bypasses the proper `GeneralSpawner` pipeline.
6. `TradeIncome` reward has no actual effect: `IncomeProcessor.ProcessTurnEnd` computes `taxIncome + tradeIncome` and ignores `PlayerNation.bonusTradeIncome`.
7. User decision: child quests should unlock when the parent quest is COMPLETED (not when claimed) — change `IsQuestUnlocked`.
