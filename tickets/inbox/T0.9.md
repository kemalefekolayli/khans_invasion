# TICKET: T0.9 — Pool floating-text popups (reduce GC churn from raid/siege/pop events)

## Context
Text popups are created fresh on every game event and destroyed seconds later, causing GC churn during active play:
- `LootPopupSpawner` (Assets\code\UI\LootPopupSpawner.cs) — per raid: `new GameObject` + `AddComponent<TextMeshPro>` + `AddComponent<FloatingLootText>` + `AddComponent<BillboardText>`, destroyed after ~2s
- `SiegePopupSpawner` (Assets\code\SiegeSystem\SiegePopupSpawner.cs:193)
- `PopulationPopupSpawner` (Assets\code\UI\PopulationPopupSpawner.cs:191)

Meanwhile `RaidSmokeController` and `SiegeSmokeController` already implement a proper object pool (`poolSize`, `spawnInterval`, return-to-pool) — that's the reference pattern to reuse.
