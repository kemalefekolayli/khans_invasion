# TICKET: T1.5 — Quest Completion Popup (3-second On-Screen Banner)

## Context
Currently when a quest completes or is claimed, the ONLY feedback is a console log (`QuestManager.cs` lines 124, 171) and a silent UI tint change in `QuestItemUI`. The user wants: when a quest completes, a text should drop onto the screen for ~3 seconds showing the quest name and its reward/bonus.

The project already has a screen-space banner primitive: `Assets/code/UI/CenterWarningPopupSpawner.cs` (self-built Canvas, sortingOrder 20000, animated fade/scale). Reuse that pattern rather than building a new system.

## Must Have
- [ ] New screen-space banner/toast that shows for ~3 seconds when a quest completes, displaying: quest title + reward description (e.g. "Quest Complete! Build 5 Buildings — Reward: +25 Population Capacity").
- [ ] Also show the banner when a quest reward is claimed (or a single banner on completion that includes the reward — pick the cleaner UX; at minimum completion must show).
- [ ] Banner is non-blocking (CanvasGroup blocksRaycasts=false), auto-destroys/returns to a pool after ~3s, appears at a consistent on-screen position (center-top or center), with fade-in/out and optional slight drop/scale animation.
- [ ] Wire it so it does not spam if multiple quests complete in the same frame (queue or coalesce; at minimum show sequentially).

## Done When
- [ ] Completing a quest shows the on-screen banner with quest name + reward for ~3s
- [ ] Banner does not block input and disappears cleanly
- [ ] No GC churn — reuse pooling pattern from `ComponentPool.cs` (T0.9) or the existing popup spawners
