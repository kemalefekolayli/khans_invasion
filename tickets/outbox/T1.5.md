# RESULT: T1.5 — Quest Completion Popup (3-second On-Screen Banner)

## Status
DONE

## Summary
Added a non-blocking, pooled, screen-space toast banner that shows for ~3 seconds when a quest completes (quest title + reward, e.g. `Quest Complete! Build 5 buildings. — Reward: Gain +25 max pop cap in ALL your provinces.`) and again, briefly, when its reward is claimed (`Reward Claimed! ...`). It reuses the self-built-canvas pattern from `CenterWarningPopupSpawner.cs` (no prefab) and the `ComponentPool` from T0.9, and queues messages so multiple quests completing in the same frame are shown sequentially. It hooks QuestManager's existing C# events `OnQuestCompleted`/`OnQuestClaimed`; no new GameEvents and no change to `QuestManager.cs` was required.

## Notes / Issues
- **Design decision (Must Have 2):** chose the "single banner on completion including the reward" UX for completion AND a distinct short "Reward Claimed!" toast on claim. Both QuestManager events are wired (no dead event subscription), and claim happens at a separate later moment so the two toasts don't overlap or feel redundant.
- **No change to `QuestManager.cs`:** the spawner subscribes to `QuestManager.Instance`'s events in `OnEnable`/`OnDisable` exactly like `QuestItemUI` already does, so the "Files Touched" hook is satisfied without modifying the manager.
- **Self-instantiation:** the spawner builds itself at runtime via `[RuntimeInitializeOnLoadMethod(AfterSceneLoad)]` (same as `CenterWarningPopupSpawner`); QuestManager is a GameScene scene object whose `Awake` runs before `AfterSceneLoad`, so `QuestManager.Instance` is available when the spawner subscribes (null-guarded anyway for the menu scene).
