DONE

## Summary
Added a minimal file sink for `GameLog` so headless/agent runs are inspectable. New static helper `GameLogFileSink` (default path `Logs/game_log.txt`, project-relative, gitignored) appends each enabled log line with a timestamp using `File.AppendAllText` (flush-per-line). It is wired into the existing `GameLog.Log/Warning/Error` methods at the same `GameLog.IsEnabled(category)` filter point — no parallel logging system, no buffering/async/rotation. Path + enable toggle exposed as `[SerializeField]` on the existing `GameLogManager` via `GameLogFileSink.Configure(...)`.
