==================================================================================
Branch: feature/t1.7-quest-panel-polish
Status: DONE (merged to main, tagged v0.6)

Changes
-------
1. Smaller quest squares
   - QuestPanelController.cs: nodeWidth 200->130, nodeHeight 140->90,
     columnSpacing 210->160, rowSpacing 200->140, treePadding 20->15.
   - QuestPanelCanvas.prefab: QuestItem template SizeDelta 200x140 ->
     130x90; Title 188x48->122x36; Progress 188x30->122x22; Arrow 24x24->
     16x16. Serialized controller values updated to match code defaults.

2. Vertical scrollbar moved to the LEFT + scroll actually usable
   - Prefab: vertical scrollbar RectTransform (fileID 4800000000000002008)
     flipped from right-anchored (AnchorMin {1,0}/AnchorMax {1,1}/pos
     {-8,0}/pivot {1,0.5}) to LEFT (AnchorMin {0,0}/AnchorMax {0,1}/pos
     {0,0}/pivot {0,0.5}).
   - Viewport inset by 16px on the left (AnchoredPosition x:16,
     SizeDelta x:-16) so content isn't hidden under the left scrollbar.
   - ScrollRect wiring untouched: m_VerticalScrollbar still
     4800000000000003010, m_Viewport still 4800000000000002002.

3. Visible line between quests (connectors)
   - Root cause: AddConnectorRect created an Image with NO sprite assigned,
     which renders nothing, so the runtime connector lines were invisible.
   - Fix: assign a generated white sprite (GetWhiteSprite(), same 1x1
     white-texture pattern used in QuestCompletionPopupSpawner.cs) to the
     connector Image.
   - Also brightened lockedConnectorColor 0.3 -> 0.55 gray and bumped
     connectorThickness 3 -> 6 so lines are clearly visible even for
     locked (unconnected) quests. unlockedConnectorColor unchanged (gold).
